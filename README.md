# my_web_based_jumper_game
A platformer in your browser.
Firstly i wanted to make a game similar to fire and water, which is my childhood game where i spent most of my time. However during the making process i decided to make a game about a robber who is grabbing fruits instead of money. 

Description:
Main menu:
you have play button, which starts the first level. Options button, which redirects you to the options tab where you can change background of the current level, change your keybinds. 
Levels button, where you can change your level for now there are only 2 levels might add more levels and boss fight. 
And lastly the quit button which quits the game.

If you press the play without changing your keybinds. Your default keybinds are right arrow for movement to the right, left arrow for movement to the left and space button for jump and double jump. 

There are Apples, Cherries, Bannanas as fruits which adds the fruit count to the top left corner for the coresponding fruit. And there are destructible boxes, which drop apples and the count of destroied boxes is added to the top left corner. Also there are checkpoints which save the position where you touched the checkpoint and when you die you can respawn to that position. 


How to Play My Game
To run this game on your computer:
  just press the demo link
  demo link: https://64-pixel.github.io/my_web_based_jumper_game/
